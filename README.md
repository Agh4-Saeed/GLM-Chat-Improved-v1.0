# GLM Chat Improved V1.0

**A modern desktop AI chat client for local GLM models.**

GLM Chat Improved is a modern desktop application featuring a sleek neon-dark interface, Persian and English language support, and integration with local GLM models through [AutoZcoder](https://github.com/B3hnamR/AutoZcoder).

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![PySide6](https://img.shields.io/badge/UI-PySide6-green)
![License](https://img.shields.io/badge/License-MIT-yellow)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

---

## ✨ Features

- 🎨 Modern desktop interface with dark neon and light themes
- 🌐 Full Persian and English language support, including RTL layout
- ⚡ Real-time streaming responses
- 🤖 Support for selecting different available models
- 📎 File and image attachments with drag-and-drop support
- 💬 Chat history with multiple conversations
- 📋 One-click code copying
- ⏹️ Stop response generation at any time
- ⌨️ Keyboard shortcuts, including `Ctrl+N`, `Ctrl+L`, and `Escape`
- 🔐 Secure API key storage using the system keyring

---

## 🛠️ Requirements

- Python 3.10 or later
- [AutoZcoder](https://github.com/B3hnamR/AutoZcoder) installed and running
- A valid API key from your AutoZcoder account

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Agh4-Saeed/GLMChatImproved.git
cd GLMChatImproved
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python GLM_Chat_Improved.py
```

If your main Python file has a different name, replace `GLM_Chat_Improved.py` with the correct filename.
